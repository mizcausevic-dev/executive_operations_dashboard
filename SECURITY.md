# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this repository, please do not open a public issue with exploit details.

- Contact: [Mirza Causevic on LinkedIn](https://www.linkedin.com/in/mirzacausevic)
- Include: affected area, reproduction details, impact, and any suggested remediation

## Scope

This repository is a portfolio project that demonstrates frontend systems thinking, executive reporting, and operational dashboard design. It is not intended for production deployment without environment hardening, dependency review, and authentication controls.
